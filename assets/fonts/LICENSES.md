# Self-hosted faces

Both are SIL Open Font License 1.1, © 2023 Vercel, in collaboration with
basement.studio. Variable, weights 100–900.

| File | Family | Source | Bytes |
|---|---|---|---|
| `Geist-var.woff2` | Geist | npm `geist@1.3.1`, `dist/fonts/geist-sans/Geist-Variable.woff2` | 56,800 |
| `GeistMono-var.woff2` | Geist Mono | npm `geist@1.3.1`, `dist/fonts/geist-mono/GeistMono-Variable.woff2` | 58,048 |

Neither face carries Greek, so Π, η and Δ in the project write-ups fall back
to the system UI face glyph by glyph. That is deliberate: they read as
symbols, and a third download for three characters is not worth it.
